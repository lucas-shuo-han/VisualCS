## 01-Newton-Schulz迭代-奇异值去哪儿

- `00:06` 取一个数，反复把它代入同一个三次多项式。
- `00:10` 从三个挨得很近的数出发：2.00、2.20 和 2.23。
- `00:15` 每迭代一步，它们都在正负之间来回跳……
- `00:21` 最后，2.00 停在 −1，2.20 停在 +1，2.23 又回到了 −1。
- `00:26` 起点只差一点点，终点却正负交替。为什么？这就是这支视频要解开的谜。
- `00:34` Newton–Schulz 迭代来自 CS182 第五次讨论课：它反复改写一个矩阵 W，这个多项式就藏在里面。
- `00:42` 把 W 做奇异值分解：U 和 V 只负责旋转，拉伸的大小全在中间的 Σ 里。
- `00:49` 代进去一算，U 和 V 原封不动地留在两边，p 只作用在中间的 Σ 上。
- `00:56` Σ 是对角矩阵，所以每个奇异值各自独立地变成 p(σ)，互不干扰。
- `01:02` 如果所有奇异值都被推到 1，W 就只剩下 U 乘 V 的转置：一个正交矩阵。这就是“正交化”。
- `01:11` 所以可以先忘掉矩阵，只盯着一个数 x，看它在 p 的反复作用下去哪。
- `01:18` 第 (e) 问正是：奇异值从正数 σ 出发，最后去 +1、−1、0，还是发散？
- `01:25` 画出 y = p(x)，再画出对角线 y = x。
- `01:29` 这叫蛛网图。从起点竖直走到曲线，到达的高度就是下一个值 p(x)；
- `01:35` 再水平走到对角线，把这个高度搬回横轴的位置，作为新的 x。
- `01:41` 讨论课的例子从 0.3 出发：重复这两步，台阶一级一级爬向 1。
- `01:47` 从 1.2 出发，先落到 1 的下方，然后同样贴上 1。
- `01:54` 曲线和对角线的交点满足 p(x) = x，叫作不动点：一旦落在上面，就永远不动。
- `02:01` 解这个方程，化简后是 x 的立方等于 x，所以不动点是 −1、0 和 1。
- `02:08` 但不动点分两种：吸引的和排斥的。区别在于 p 在那里的斜率。
- `02:14` 在 0 处斜率是 1.5：偏差每步放大 1.5 倍。从 0.05 出发，很快就被推开。
- `02:21` 在 ±1 处斜率是 0：偏差每一步差不多被平方。从 1.2 出发，误差是 0.2、0.064、0.006……
- `02:29` 所以 0 是不稳定的不动点，像山顶；±1 是稳定的，像谷底。
- `02:36` 现在回答第 (e) 问。先把 p 分解：p(x) 等于 x 乘以 3 减 x 的平方，再除以 2。
- `02:43` 当 0 < x < √3 时，两个因子都是正的，所以 p(x) 也是正的：不会翻号。
- `02:50` 而且这一段上 p 最高只到 1，在 x = 1 处取到。所以一步之后，x 就落在 0 和 1 之间。
- `02:58` 在 0 和 1 之间，p(x) − x = x(1 − x 的平方)/2 大于 0：每步都往上走，又越不过 1，只能收敛到 1。
- `03:08` 比如从 1.6 出发：先掉到 0.35，再一级级爬回 1。0 < σ < √3 全都去 +1。
- `03:14` 恰好 σ = √3 时，p(√3) = 0：一步掉进 0，然后永远停在这个不稳定的不动点上。
- `03:22` 越过 √3，因子 3 − x 的平方变成负的：p(x) 和 x 异号。每迭代一次，符号就翻一次。
- `03:30` 那大小呢？比较 |p(x)| 和 |x|：两者的比值是 |3 − x 的平方| 除以 2。
- `03:37` 在 |x| > √3 时，这个比值小于 1，当且仅当 x 的平方小于 5，也就是 |x| < √5。
- `03:45` 于是有了第二个关键数 √5。√3 管会不会翻号，√5 管翻号的同时是变小还是变大。
- `03:54` 先看边缘。p(√5) = −√5，p(−√5) = √5：蛛网变成一个正方形，永远绕下去。
- `04:00` 所以 σ = √5 既不收敛也不发散：它在 ±√5 之间来回，是周期为 2 的轨道，不是不动点。
- `04:09` 再大一点，比如 2.3：每步翻号，还越来越大：−2.63、5.18、−61.8……发散。
- `04:17` 剩下的就是 √3 和 √5 之间。讨论课的解答说：这里要么收敛到 −1，要么发散。
- `04:24` 可开头的 2.2 明明去了 +1。这一段里到底发生了什么？
- `04:31` 这一段里每步都翻号，同时绝对值变小。我们只画绝对值，用颜色记正负，再数翻号的次数。
- `04:39` 一步一步看：绝对值不断往左走，颜色正负交替。
- `04:44` 2.00 翻一次号就跌到了 √3 以下；2.20 翻了两次，2.23 翻了三次。
- `04:51` 绝对值一直变小，却不可能永远停在 √3 右边：能让它停住的只有 √5。所以它迟早跌进 √3 以内。
- `04:59` 一旦跌进去，就不再翻号，被同号的 ±1 吸走。
- `05:04` 从正数出发：翻了奇数次，最后是 −1；翻了偶数次，最后是 +1。
- `05:12` 翻一次和翻两次的分界在哪？就在 p(x) 恰好等于 −√3 的地方。把这个点叫作 b1。
- `05:20` p 在这里单调递减，所以 √3 和 b1 之间的点，一步落到 −√3 和 0 之间：只翻一次号，然后去 −1。
- `05:28` 2 就在这一段：p(2) 正好等于 −1，一步到位。
- `05:34` 依此类推，让 p(b2) = −b1，p(b3) = −b2，一直下去：每个 b 都由上一个唯一确定。
- `05:42` 算出来：b1 ≈ 2.1478，b2 ≈ 2.2212，b3 ≈ 2.2336……它们越来越靠近 √5。
- `05:48` 把 √3 到 √5 这一段按这些点切开，只看绝对值。关键在于：p 把每一段翻到上一段的镜像上。
- `05:56` 第一段一步落进 √3 以内的负半边，去 −1。
- `06:00` p 是奇函数，镜像的命运正好相反：第二段翻一次号，就变成了第一段的镜像，所以去 +1。
- `06:09` 第三段变成第二段的镜像，又去 −1。就这样一段一段交替下去。
- `06:14` 结论：第 n 段里的点恰好翻 n 次号。n 为奇数去 −1，n 为偶数去 +1。
- `06:21` 这些分界点越来越挤向 √5。放大去看，同样的图案一遍又一遍地重复。
- `06:28` 每一段大约只有上一段的六分之一：p 在 √5 处的斜率是 −6，离 √5 的距离每步放大 6 倍。
- `06:37` 所以在 √3 和 √5 之间，有无穷多个吸引区，交替通向 −1、+1、−1、+1……
- `06:44` 那分界点本身呢？b1 一步到 −√3，再一步到 0。
- `06:49` b2 → −b1 → √3 → 0，b3 → −b2 → b1 → −√3 → 0。
- `06:55` 每个分界点经过有限步都精确撞上 ±√3，然后落在不稳定的不动点 0 上：既不去 +1，也不去 −1。
- `07:03` 不过它们都是孤立的点：稍微推一下，就会掉进两边的某个吸引区。
- `07:11` 把第 (e) 问的答案整理一下。
- `07:14` 0 到 √3 之间去 +1；√3 本身一步到 0。
- `07:18` √3 到 √5 之间按翻号次数交替去 −1、+1；分界点 bn 落到 0。
- `07:24` √5 在 ±√5 之间来回；再大就一边翻号一边发散。
- `07:30` 回到矩阵。一个奇异值若被推到 −1，矩阵依然正交，只是那个方向被翻转了；但大于 √5 的奇异值会发散。
- `07:39` 所以迭代之前要先把 W 缩小。常见做法是除以 Frobenius 范数：它不小于最大的奇异值。
- `07:47` 缩放之后，所有奇异值都落进 0 和 1 之间，远离 √3。
- `07:52` 接下来每个奇异值都走上通往 +1 的路；小的要多走几步，但最终都到 1，W 趋向 U 乘 V 的转置。
- `08:01` 一个矩阵问题，就这样变成了一维动力系统：不动点、稳定性、两个关键数，和它们之间无穷交替的吸引区。
