# Notes → 3Blue1Brown-style videos, strict edition

The runbook, templates and scripts live in the sibling skill folder, so that both
editions share one kit:

    ../notes-to-3b1b-video/STRICT.md

Read that file now and follow it step by step. In it, `K` is the folder
`../notes-to-3b1b-video` (next to the folder this file is in). Do not read that
folder's `SKILL.md` or `references/`: they are the other edition.

If `../notes-to-3b1b-video/STRICT.md` does not exist, the main skill is not installed:
say so and stop.
