# Script (author)

Heard, not read. Read each scene's beats in order in your head; if it sounds like bullet points, it is. `board_lint.py` catches the mechanical cases.

## Beats
- A beat (one `### id`) is 2–4 sentences about one picture, ≤ 60 words. New beat when the picture changes subject.
- A line break inside a beat is a paragraph: use it where the thought turns, in any beat over ~60 words.
- A change "on" a phrase: a few words copied from the beat, unique in it.

## Sentences
- 10–25 words, varied, each starting from the last ("so", "which means", "now").
- Plain words, contractions, at most one subordinate clause.
- Numbers and symbols as words; round aloud, exact value on screen. No colons.
- One name per thing (GLOSSARY.md).
- Never a run of short beats; no slide fragments ("Why 12 bits?", "Done!").
- Notation on screen, the idea aloud. Where a subtitle must carry notation, give a `speak:` line with the same number of sentences.
- Avoid wordings that sound like other words ("with n" heard as "within"): say "with n numbers" as "with a list of n numbers".

## Length
~140 words per minute of video. Count words per episode; split rather than run long.

Not yours: how terms are pronounced (the pronouncer), voice, speed and pauses (the coordinator with the user).
