# Production

## Coverage
1. Notes → clean Markdown in scratch.
2. List every substantive item (concept, rule, table, example, exercise); keep the notes' own examples and numbers.
3. Map item → episode → beat in `COVERAGE.md`; an omission needs a reason.
4. Recompute every example. Notes contain errors: show the correct one, report the difference.

## Planning
- Length from content: one idea 3–4 min, a chapter 6–8, more = two episodes.
- Order and titles in `series.py`. `GLOSSARY.md`: one term, one colour, one spoken form.

## The user
- First voiced 480p preview early, with its exact path. Review clips voiced, subtitled, one scene each.
- Big rework: task list first, report against it.
- 1080p renders once, in the background, after review. Ask before deleting old videos.

## Delivery
- [ ] `check.py` PASS per episode
- [ ] `render.py U --out videos/<course>-<unit>`; `pace.py` numbers in the report
- [ ] 1080p spot check: sheets of 2–3 episodes, one heard
- [ ] `srt_to_script.py`; README with episode table and how to re-render
- [ ] commit; final message: paths, episodes, coverage, notes errors, what was not checked

## Publishing (only when asked)
The user uploads, as Private, in their own browser. The description discloses: unofficial, not affiliated with the course, AI-assisted, synthetic voice, Manim, 3b1b-inspired. Raise course policy and voice licence first.
